## Purpose
A product nobody can reach is not a product. Plan distribution with the same rigor as the build, starting with the hardest part: the first 100 real users.

## Structure
- **First 100 plan**: the specific, unscalable way to reach the first users (communities, direct outreach, one channel done well). Name where they already gather.
- **Activation**: the single action that means a new user got value; how soon it should happen.
- **Retention hook**: why a user returns next week (habit trigger, accumulated value, network).
- **Growth loop**: one loop where usage drives more usage or more users (content, referral, network). State each step.
- **Metrics**: North Star plus one activation metric and one retention metric.

## Method
1. Pick ONE primary channel and go deep before adding more.
2. Separate acquisition from activation from retention; a leak in any one wastes the others.
3. Prefer a loop over a one-time campaign.

## Anti-patterns
- "We'll do content, SEO, ads, and partnerships" with no focus or sequence.
- Counting signups as success while activation is unmeasured.
- Inventing channel conversion rates; mark estimates as assumptions to test.

## When NOT to use
Before there is any evidence of demand, deep GTM planning is premature; validate the problem first.
