## Purpose
Trace the real path a user takes from trigger to outcome and expose the moments where intent leaks away. Friction at the wrong step wastes every later improvement.

## Structure
For each stage (Trigger, Onboard, First value, Habit, Expansion):
- **Action**: what the user does.
- **Thought / question**: what they are unsure about.
- **Emotion**: confidence or anxiety.
- **Friction**: what blocks or slows them.
- **Drop-off risk**: high / medium / low and why.
Mark the single moment of first value ("aha"); everything before it must be ruthless.

## Method
1. Walk the path as the user, not as the org chart.
2. Identify the one stage with the biggest gap between intent and completion; fix that first.
3. Note empty, error, and waiting states at each stage; they are part of the journey.

## Anti-patterns
- Happy-path-only maps that ignore errors and empty states.
- Mapping the screens the team built rather than the goal the user has.
- Friction labeled without a drop-off consequence.

## When NOT to use
For a one-step utility action, a journey map is overkill; check the empty and error states and move on.
